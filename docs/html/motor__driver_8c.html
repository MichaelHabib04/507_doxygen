void motor_set_duty_cycle ( motor_t * p_mot,
int8_t duty_cycle )

Set the motor drive duty cycle.

Set the motor duty cycle as a percentage of the timer period.

The duty cycle is converted from a percentage to a timer compare value using the timer auto-reload register. The second output channel is set to zero.

Parameters
p_motPointer to the motor configuration.
