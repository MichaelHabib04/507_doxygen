Initialize a TDS probe state structure. 

The probe starts with zeroed ADC, voltage, and ppm values. Temperature is set to 25 degrees Celsius, which is the reference temperature for the compensation calculation used by \doxylink{probe_8h_ad2c191421817da3548d6f5828caf601e}{tds\+\_\+read\+\_\+ppm()}.

Read the TDS probe and calculate the compensated ppm value.

The ADC reading is converted to volts using the configured reference voltage. A temperature compensation factor is applied before the TDS polynomial is evaluated.
