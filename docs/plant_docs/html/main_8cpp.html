◆ Actions

enum class Actions
strong

High-level actions that can be requested by the TCP controller.

Enumerator
Add_Water 

Add water until the float switch indicates the target level.

Add_Slop 

Add nutrient solution/slop and report the current TDS value.

Controller_Mode 

Return control to manual/controller-command mode.

Automatic_Mode 

Automatically manage water level and TDS concentration.

Waiting_For_Command 

Idle state while waiting for the next TCP command.
