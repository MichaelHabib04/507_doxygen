\doxysubsection{Detailed Description}
Interface for reading and reporting TDS probe measurements. 

This module reads a TDS probe through an ADC channel, converts the ADC count to voltage, applies temperature compensation, estimates parts-\/per-\/million, and can print the latest reading over UART.
